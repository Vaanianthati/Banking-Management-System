# Banking Management System

## Project Title

Banking Management System

## Project Description

The Banking Management System is a Java-based application developed using Java Swing, JDBC, and MySQL. The project automates banking operations such as deposits, withdrawals, balance enquiry, and transaction management. It provides a simple and efficient way to manage customer banking activities.

## Features

* Deposit Money
* Withdraw Money
* Balance Enquiry
* Transaction Management
* Simple User Interface
* Java-Based Implementation
* Error Handling
* Account Balance Management

## Software Requirements

* Java JDK 8 or Above
* Apache NetBeans IDE
* Windows Operating System
* GitHub Account

## Steps to Run the Project

1. Install Java JDK.
2. Install Apache NetBeans IDE.
3. Open the BankingManagementSystem project.
4. Open BankingManagementSystem.java.
5. Compile and Run the project using F6.
6. Use the menu options to perform banking operations.
